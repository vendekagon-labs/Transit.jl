## Contributing

Transit.jl is maintained by [Vendekagon Labs](https://github.com/vendekagon-labs).
Report problems and suggest changes with GitHub
[issues](https://github.com/vendekagon-labs/Transit.jl/issues).

Pull requests are welcome, but make sure they're well tested first: add tests
for what you change, and check that the tests
(`julia --project -e 'using Pkg; Pkg.test()'`) and transit-format's verify
harness (`bin/verify`, which needs the
[clojure CLI](https://clojure.org/guides/install_clojure)) pass.
